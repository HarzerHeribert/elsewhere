# Elsewhere — digital lives, shared worlds

Outlined serif identity, original character artwork, and an eight-second RAEA ident. The application uses the SVG identity and the updated Three.js creature; RAEA is an external authoring tool, not a runtime dependency.

## Preview and exports

Run `pnpm dev:web`, then open `http://127.0.0.1:5173/brand/index.html`. The product's About dialog introduces the shared world; this separate gallery contains the downloadable brand assets.

Public exports live in `elsewhere/web/public/brand/`:

- `elsewhere-mark.svg`: crooked doorway / navigation arrow.
- `elsewhere-wordmark.svg`: Averia Serif Libre Bold, subtly offset and exported as filled outlines.
- `elsewhere-lockup.svg` and `elsewhere-lockup-light.svg`: transparent full lockups.
- `hubert.svg`: deadpan, lopsided character with three feet and one tooth.
- `elsewhere-ident.mp4`: 1280 × 720, 30 fps, eight seconds, silent, fast-start H.264.
- `elsewhere-ident-poster.png`: settled frame for previews and reduced-motion contexts.

The gallery plays video only on request. UI flourishes honor reduced motion.

## Source and regeneration

`elsewhere/web/src/brandArtwork.ts` holds the shared character and doorway geometry. The licensed serif wordmark is generated by `python3 scripts/generate-wordmark.py` (requires fontTools), with its SIL OFL license in `type/OFL.txt`. Run `node --import tsx scripts/export-brand-assets.ts` to regenerate public SVGs, favicon, and motion media from that source. `characters/hubert/appearance.json` and `elsewhere/web/src/HubertCreature.ts` hold the corresponding 3D palette, face and gait.

`motion/elsewhere-ident.tsx` is the editable RAEA composition. Its adjacent `media/` folder makes it portable. It uses only local artwork, no remote assets, fonts, models, audio or native calls. With the reviewed engine available externally:

```sh
RAEA_OFFLINE=1 RAEA_ENV_FILE=/dev/null RAEA_AUDIO_AUTOSETUP=0 RAEA_PAGE_MCP_PORT=0 raea render motion/elsewhere-ident.tsx -o elsewhere-ident.mp4 --quality high
```

Use OS sandboxing for untrusted rendering tools; offline mode alone is not isolation. The actual task render used a separate temporary project, an empty inherited environment, and a macOS sandbox denying network access and reads of the user's home. No installation scripts, optional setups, hooks or agent configuration changes were executed.

See `raea-review.json` for the two-agent source review, exact release hash, findings and limits. The verified engine archive remains outside this repository. Do not silently upgrade that pin.

## Visual direction

Two calm base colors: deep ink `#243b36` and warm paper `#f4f0e4`. One muted terracotta accent `#99583f`. Surface and status variants use tints of those colors. The character illustration retains its natural coat and feet. Uneven proportions, deliberate pauses, and deadpan curiosity. Hubert's expression comes from heavy uneven eyelids, small matte pupils, an off-center nose and flat mouth. His paddle feet arrive at slightly different times. Avoid eye sparkles, blush, baby proportions and constant bouncing.

The live design system is at `/design-system.html`. Its tokens live in `elsewhere/web/src/ui/tokens.css`; the gallery receives an exported copy through the asset export script.

Product positioning centers the interaction between people, agents, and a simulated world. Hubert is the first resident, not the premise. Public descriptions focus on decisions, memories, creations, and participation; appearance details belong to asset documentation.
